# Glossary supplement — prototype-game

Terms used by `spec/prototype-game.md` that `spec/glossary.md` does not hold. For merge by the orchestrator.

- **homogeneous coordinates** — a point representation with an added third component equal to 1, so one 3x3 matrix applies rotation and translation together
- **separating axis theorem** — the convex-polygon collision test: two convex shapes are disjoint exactly when some edge normal gives projections with a gap
- **Dijkstra's algorithm** — the standard shortest-path graph search that settles nodes in order of increasing distance
- **NetworkX** — the Python graph library used by the game code
- **blit** — the graphics operation that copies one pixel surface onto another, optionally through a blend mode
- **coefficient of variation** — the standard deviation divided by the mean, a scale-free measure of spread
